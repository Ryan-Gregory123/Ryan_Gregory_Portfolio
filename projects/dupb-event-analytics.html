Event Data Model & Power BI Reporting

I created a dimensional database to house event data, then used Power BI to build visualizations from it.

Project overview

I started by building a dimensional database to give the event information a consistent structure. Once the data was organized, I used Power BI to create visualizations that made it easier to review and understand. Working through both parts helped me see how much the quality of a report depends on the way the underlying data is organized.

Work completed

  • Designed a dimensional database to organize event information.
  • Set up the data so it could be queried and used in reports.
  • Used Power BI to create visualizations from the database.

Tools & concepts

Dimensional modelingDatabase designPower BIData visualization

Project focus

The project helped me connect database design with the reporting side of analytics. It reinforced that useful visualizations start with data that has been organized thoughtfully.
