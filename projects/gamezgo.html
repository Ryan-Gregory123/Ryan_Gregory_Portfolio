GameZGo Database & Data Mart

I designed a database and data mart for a fictional video game retailer, using practical sales and customer questions to guide the structure.

Project overview

For this project, I used a fictional video game retailer as the setting for a database and business intelligence design. I began with a normalized relational database, then developed a dimensional data mart that could support reporting. Starting with business questions helped me think about what information the database needed to make available.

Business questions

  • Which games sell the most units and generate the most revenue at each store?
  • Which store location generates the highest revenue each year?
  • Which quarter performs best based on revenue and profit?
  • How many new customers does the business gain each month?
  • Do sales increase during the Christmas season, and which products contribute to the increase?

Technical work

  • Building a third-normal-form relational database structure in SQL Server.
  • Designing a dimensional data mart with fact and dimension tables to support analysis.
  • Developing SQL queries to answer business questions.
  • Working with SQL Server Integration Services (SSIS) and Visual Studio for data movement and transformation.

Tools & concepts

SQL ServerSQL3NFDimensional modelingFact & dimension tablesSSISVisual Studio

Business value

This project helped me understand the connection between database structure and the questions a business wants to answer. A well-designed data model is not just about storing information; it should make useful analysis possible.
